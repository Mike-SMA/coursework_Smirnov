# Auth Service

## Описание
Сервис аутентификации и авторизации пользователей на базе JWT-токенов.

## Задачи сервиса
- Регистрация новых пользователей
- Аутентификация пользователей (выдача access и refresh токенов)
- Обновление access токена через refresh токен
- Обновление данных пользователя
- Просмотр истории входов
- Выход из системы (инвалидация токена через Redis)

## Логика работы
1. Пользователь регистрируется через `/register`
2. Входит через `/login` — получает `access_token` (15 мин) и `refresh_token` (30 дней)
3. `access_token` передаётся в заголовке `Authorization: Bearer <token>` для доступа к защищённым эндпоинтам
4. При истечении `access_token` — обновляется через `/refresh`
5. При выходе токен помещается в чёрный список Redis

## Стек
- FastAPI, SQLModel, PostgreSQL, Redis, JWT (python-jose), passlib/bcrypt

## Запуск

### 1. Создать .env файл
```bash
cp .env.example .env
```

### 2. Запустить базы данных
```bash
docker-compose up -d
```

### 3. Установить зависимости
```bash
pip install -r requirements.txt
```

### 4. Запустить сервис
```bash
uvicorn main:app --reload --port 8001
```

### 5. Документация
Открыть в браузере: http://127.0.0.1:8001/docs

## Эндпоинты
| Метод | Путь | Описание |
|-------|------|----------|
| POST | /register | Регистрация |
| POST | /login | Вход |
| POST | /refresh | Обновление токена |
| PUT | /user/update | Обновление данных |
| GET | /user/history | История входов |
| POST | /logout | Выход |
