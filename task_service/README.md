# Task Service

## Описание
Сервис управления задачами. Все эндпоинты защищены JWT-аутентификацией. Каждый пользователь видит и управляет только своими задачами.

## Задачи сервиса
- Создание задач с названием, описанием, статусом, приоритетом и дедлайном
- Получение списка задач с фильтрацией по статусу и приоритету
- Обновление задачи
- Удаление задачи

## Логика работы
1. Для доступа к любому эндпоинту необходим валидный `access_token` от Auth Service
2. Токен передаётся в заголовке: `Authorization: Bearer <token>`
3. `user_id` извлекается из JWT токена — каждый пользователь работает только со своими задачами
4. Статусы задач: `todo`, `in_progress`, `done`
5. Приоритеты: `low`, `medium`, `high`

## Связь с Auth Service
Task Service проверяет JWT токены напрямую через общий `SECRET_KEY` без HTTP запросов к Auth Service.

## Стек
- FastAPI, SQLModel, PostgreSQL, python-jose

## Запуск

### 1. Убедитесь что Auth Service запущен (порт 8001)

### 2. Создать .env файл
```bash
cp .env.example .env
```
Убедитесь что `SECRET_KEY` совпадает с `auth_service/.env`

### 3. Запустить базу данных
```bash
docker-compose up -d
```

### 4. Установить зависимости
```bash
pip install -r requirements.txt
```

### 5. Запустить сервис
```bash
uvicorn main:app --reload --port 8002
```

### 6. Документация
Открыть в браузере: http://127.0.0.1:8002/docs

В Swagger нажать **Authorize** и вставить токен из Auth Service.

## Эндпоинты
| Метод | Путь | Описание |
|-------|------|----------|
| POST | /api/v1/tasks/ | Создать задачу |
| GET | /api/v1/tasks/ | Список задач (фильтр по status, priority) |
| GET | /api/v1/tasks/{id} | Получить задачу |
| PUT | /api/v1/tasks/{id} | Обновить задачу |
| DELETE | /api/v1/tasks/{id} | Удалить задачу |
